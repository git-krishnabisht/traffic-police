traffic-police

The Maven repository of traffic-police's Android libraries: io.trafficpolice:capture, capture-noop and capture-core. Add it to settings.gradle.kts:

dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven("https://git-krishnabisht.github.io/traffic-police/maven") {
            content { includeGroup("io.trafficpolice") }
        }
    }
}

How to use it: the README.
