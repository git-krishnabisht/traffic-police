A big release: traffic-police now shows WebSockets, gRPC calls and Flutter apps' traffic, has a
form for rules, installs with one command, and its Android library is published, so apps no
longer build it themselves. It also fixes two crashes that 0.3.1 has.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/git-krishnabisht/traffic-police/master/install.sh | sh
```

On Windows, in PowerShell:
`irm https://raw.githubusercontent.com/git-krishnabisht/traffic-police/master/install.ps1 | iex`.
The installer takes the file for your system from this page, checks it against `SHA256SUMS.txt`,
puts it in `~/.local/bin` (on Windows `%LOCALAPPDATA%\Programs\traffic-police`) and adds that
folder to your PATH; running it again updates. The README's Install section has the options.

## New

- **WebSockets.** The handshake and every message, in library and attach mode: the Response tab
  lists a socket's messages, and Enter opens one. In library mode, open sockets with
  `TrafficPolice.newWebSocket(client, request, listener)`; attach mode needs nothing. HAR files
  keep the messages as Chrome does (`_webSocketMessages`).
- **gRPC** (grpc-java 1.21 and newer, any transport). Each call is one row, with its messages
  (decoded as protobuf), its status in the Status column (`OK`, `NOT_FOUND`, …) and its trailers;
  `grpc:not_found` or `grpc:error` filters by status. In library mode, add
  `TrafficPolice.grpcInterceptor()` to each channel; attach mode needs nothing.
- **Flutter apps** (`--mode flutter`). A Flutter app's own traffic (package:http, dio, images)
  goes through dart:io, past OkHttp. traffic-police reads it from the app's Dart VM service, as
  DevTools does: no library and no agent, in any debug or profile build of Flutter 3.22 or newer.
- **A form for rules.** In the Rules view, Enter opens a rule in a form, `r` makes one from the
  selected request, and `K` `J` move rules (they apply in order). Every field is checked as you
  type, and saving changes only that rule in `rules.toml`, keeping its comments.
- **The Android library is published**, in traffic-police's Maven repository on GitHub Pages.
  Add `maven("https://git-krishnabisht.github.io/traffic-police/maven")` to your repositories,
  then `debugImplementation("io.trafficpolice:capture:0.4.0")` and
  `releaseImplementation("io.trafficpolice:capture-noop:0.4.0")` (README, library mode).
- **One-line install** on macOS, Linux and Windows (above).
- **The body box can be turned off**: `[ui] body_box = false` starts without it, and `B` hides
  and shows it while running.
- Attaching as an app starts (`--launch`) is now tried on Android 8.1 to 10 (API 27 to 29): it
  captures from the app's first request, as on newer versions.
- On a device whose shell cannot read the list of sockets, traffic-police finds the app by its
  socket's name instead of waiting forever.
- `doctor` says how to fix every failure it reports. `[adb] path` is the adb that starts the
  server when none runs, and `package` in `.traffic-police/project.toml` skips the app picker.
- Android Studio's network inspector in the same app is reported: it can rewrite the response
  headers the app sees.

## Changed

- **Quitting is `:q` and Enter**, as in Neovim (`:q!`, `:qa`, `:wq` and `:x` too, also in the
  device and app pickers). `q` and Ctrl+C no longer quit the UI; they say how. `quit = ["q"]`
  under `[keymap]` brings `q` back.
- Menus, the column chooser, the palette and the pickers follow `[keymap]`, and a menu entry's
  letter wins over the keys that move, so the copy menu's `q` and `k` and the value menu's `j`
  work.
- A HAR entry's time is now the sum of its timings, as HAR 1.2 asks; exports are checked against
  its schema.

## Fixed

- **A crash when opening a request in a short detail pane**, for example at 120×30 with
  `graph_height = 14`, or with `gap = 3` at 30 rows (since 0.2.0).
- **A crash showing an XML or HTML body with a non-breaking space inside a tag** (found by the new
  fuzz tests).
- An attach right after the app started could miss its first OkHttp calls: the agent's hooks
  went in after the app's socket opened.
- `export --help` showed an example that the command refused.
- Values from a device far out of range (times, body offsets) no longer overflow the host's
  arithmetic (also found by fuzzing).
- On Windows, the spill folders of traffic-police processes that have exited are removed.

## Compatible with earlier versions

The protocol between the app and traffic-police is still version 1, and each side skips what it
does not know: apps built with the 0.1.0 library work with this release, and apps with the 0.4.0
library work with an older traffic-police (without the WebSocket messages and gRPC details). The
attach agent inside the binary is 0.2.0; an app that an earlier traffic-police attached to keeps
that agent until it restarts. Session files and `config.toml` files from earlier versions keep
working.

## Downloads

| File | For |
|---|---|
| `traffic-police-macos-arm64` | macOS on Apple silicon |
| `traffic-police-linux-x86_64` | Linux on x86_64 with glibc 2.34 or newer (RHEL 9, Ubuntu 22.04, Debian 12, Fedora 35 and later) |
| `traffic-police-windows-x86_64.exe` | Windows 10 and 11 on x86_64 |

`SHA256SUMS.txt` has their checksums, `LICENSE` is the Apache License 2.0, and
`THIRD-PARTY-LICENSES.txt` lists the licenses of what the binaries contain.

You also need adb (Android SDK platform-tools), and a device or emulator with Android 8.0 (API 26)
or newer. The binaries are not code-signed. The installer takes care of that; if you download a
file yourself, make it executable (`chmod +x`) on macOS and Linux, and on macOS run
`xattr -d com.apple.quarantine traffic-police-macos-arm64`, since macOS refuses a downloaded file
from an unidentified developer. Windows may warn that the publisher is unknown.

## Known limits

- gRPC in attach mode: calls an app makes with `channel.newCall` on a channel it built before the
  attach are not seen (calls through stubs are).
- Flutter mode misses requests made before it connected, shows a body once its request has
  ended, and cannot apply rules.
- Not captured: Cronet, WebView, native sockets, and an OkHttp whose names a minified debug build
  changed (`doctor` shows the hooks' status).
- No build for Intel Macs or Linux on ARM yet: build from source (README).
